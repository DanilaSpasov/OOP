# Проект: OOP

## Описание

В рамках данного задания реализованы классы `Product` и `Category` для представления товаров и их категорий.

### Класс Product

Класс предназначен для хранения информации о товаре.

Атрибуты экземпляра:

* `name` — название товара;
* `description` — описание товара;
* `price` — цена товара;
* `quantity` — количество товара на складе.

Атрибут класса:

* `product_count` — хранит количество созданных объектов класса `Product`.

При создании нового объекта значение `product_count` автоматически увеличивается на единицу.

### Класс Category

Класс предназначен для хранения информации о категории товаров.

Атрибуты экземпляра:

* `name` — название категории;
* `description` — описание категории;
* `products` — список товаров, относящихся к категории.

Атрибут класса:

* `category_count` — хранит количество созданных объектов класса `Category`.

При создании нового объекта значение `category_count` автоматически увеличивается на единицу.
