# Проект: OOP

## Описание

В рамках проекта реализована система управления товарами и категориями товаров.

В проекте реализованы следующие классы:

* `Product` — базовый класс товара;
* `Category` — класс категории товаров;
* `Smartphone` — класс смартфонов, наследующий `Product`;
* `LawnGrass` — класс газонной травы, наследующий `Product`.

---

### Абстрактный класс BaseProduct

Класс `BaseProduct` является абстрактным базовым классом для всех типов товаров в проекте. Он определяет общий интерфейс, который должны поддерживать все классы продуктов.

Класс используется в качестве родительского для класса `Product`, а также для его наследников (`Smartphone`, `LawnGrass` и других типов товаров).

Основная задача `BaseProduct` — обеспечить единый подход к работе с объектами товаров и определить обязательную функциональность для всех продуктов.

---

### Класс MixinLog

Класс `MixinLog` реализует дополнительную функциональность логирования при создании объектов товаров.

Миксин используется в качестве родительского класса для `Product` и его наследников. После создания объекта в консоль выводится его строковое представление, сформированное методом `__repr__`.

Пример вывода:

```
Product('Смартфон', 'Описание товара', 50000, 10)
```

Использование миксина позволяет вынести логику логирования в отдельный класс и избежать дублирования кода в классах товаров.

## Класс Product

Класс предназначен для хранения информации о товаре.

### Атрибуты экземпляра

* `name` — название товара;
* `description` — описание товара;
* `quantity` — количество товара на складе. Если количество указано 0, то программа завершит свою работу с ошибкой и следующим текстом: Товар с нулевым количеством не может быть добавлен.

### Приватные атрибуты

* `__price` — цена товара.

### Реализованный функционал

* Создание объектов товаров.
* Создание объекта товара из словаря с помощью классового метода `new_product()`.
* Инкапсуляция цены товара через приватный атрибут `__price`.
* Получение цены через свойство `price`.
* Изменение цены через сеттер `price`.
* Запрет установки нулевой и отрицательной цены.
* Подтверждение пользователя при попытке уменьшить цену товара.
* Переопределение метода `__str__()` для удобного строкового представления товара.
* Переопределение метода `__add__()` для вычисления суммарной стоимости двух товаров на складе.
* Генерация исключения `TypeError` при попытке сложения товара с объектом другого типа.

### Формат вывода объекта Product

```
print(product)
```

Результат:

```
Название товара, 1000 руб. Остаток: 5 шт.
```

### Сложение товаров

```
product_1 + product_2
```

Результат:

```
цена_товара_1 * количество_товара_1 +
цена_товара_2 * количество_товара_2
```

## Класс Category

Класс предназначен для хранения информации о категории товаров.

### Атрибуты экземпляра

* `name` — название категории;
* `description` — описание категории.

### Приватные атрибуты

* `__products` — список товаров категории.

### Атрибуты класса

* `category_count` — количество созданных категорий;
* `product_count` — количество товаров в категории.

### Реализованный функционал

* Создание категорий товаров.
* Подсчет количества созданных категорий.
* Хранение списка товаров в приватном атрибуте.
* Добавление новых товаров в категорию через метод `add_product()`.
* Проверка типа добавляемого объекта.
* Возможность добавлять только объекты класса `Product` и его наследников.
* Генерация исключения `TypeError` при попытке добавить объект неподходящего типа.
* Получение информации о товарах категории через геттер `products`.
* Переопределение метода `__str__()` для отображения общего количества товаров в категории.
* Метод `middle_price` вычисляет среднюю стоимость товаров, находящихся в категории.


### Формат вывода списка товаров категории

```
print(category.products)
```

Результат:

```
Название товара, 1000 руб. Остаток: 5 шт.
Другой товар, 2000 руб. Остаток: 3 шт.
```

### Формат вывода объекта Category

```
print(category)
```

Результат:

```
Смартфоны, количество продуктов: 15 шт.
```

## Класс Smartphone

Класс представляет смартфоны и наследуется от класса `Product`.

### Дополнительные атрибуты

* `efficiency` — производительность;
* `model` — модель устройства;
* `memory` — объем встроенной памяти;
* `color` — цвет устройства.

### Реализованный функционал

* Наследование всех возможностей класса `Product`.
* Хранение характеристик смартфона.

### Пример создания объекта

```
smartphone = Smartphone(
    "iPhone 15",
    "Смартфон Apple",
    120000,
    10,
    98.5,
    "15 Pro",
    256,
    "Black"
)
```

## Тестирование

Для проверки корректности работы классов и методов используются тесты, написанные с помощью библиотеки `pytest`.

В проекте протестированы следующие сценарии:

### Класс Product

* корректная инициализация объекта товара;
* работа геттера и сеттера цены;
* запрет установки отрицательной и нулевой цены;
* строковое представление объекта (`__str__`);
* представление объекта для разработчика (`__repr__`);
* сложение товаров одного типа через метод `__add__`;
* выброс исключения `ValueError` при создании товара с нулевым количеством.

### Класс Category

* корректная инициализация категории;
* подсчет количества категорий и товаров;
* добавление товара в категорию;
* выброс исключения `TypeError` при попытке добавить объект неподходящего типа;
* строковое представление категории (`__str__`);
* вычисление средней цены товаров в категории;
* обработка случая пустой категории без возникновения ошибки деления на ноль.

### Классы Smartphone и LawnGrass

* сложение объектов одного класса (`Smartphone`);
* запрет сложения объектов разных классов (`Smartphone` и `LawnGrass`) с выбросом исключения `TypeError`.

### Класс MixinLog

* проверка корректного формирования строки методом `__repr__`.

### Фикстуры

Для уменьшения дублирования кода используются фикстуры:

* `tomato` — объект товара;
* `vegetables` — категория с одним товаром;
* `reset_count` — автоматический сброс счетчиков категорий и товаров перед каждым тестом.

### Запуск тестов

Для запуска всех тестов выполните команду:

```
pytest
```

Для просмотра покрытия кода тестами:

```
pytest --cov=src --cov-report=html
```
